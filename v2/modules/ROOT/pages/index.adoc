= Ansible for OpenShift Virtualization Migration
:page-aliases: home.adoc

Ansible for OpenShift Virtualization Migration (**Migration Factory**) is a set of Ansible playbooks with deep integration into Ansible Automation Platform (AAP). It moves virtual machines from existing hypervisors onto Red Hat OpenShift Virtualization. After you seed AAP, you run providers, maps, and waves from AAP job templates.

== Overview

Migration Factory uses Migration Toolkit for Virtualization (MTV) on the destination cluster and AAP to repeat the same sitting: prepare the environment, seed AAP, configure providers and maps, define a wave, migrate, verify, and archive.
