= Ansible for OpenShift Virtualization Migration
:page-aliases: home.adoc

Ansible for OpenShift Virtualization Migration (**Migration Factory**) is a set of Ansible playbooks with deep integration into Ansible Automation Platform (AAP). It automates moving virtual machines from existing hypervisors onto Red Hat OpenShift Virtualization, and it supports day-2 operations of those VMs on the platform.

These pages describe the collection `v2` branch. Start in the left nav after you read this introduction, or go directly to xref:journey:confirm-openshift-ready.adoc[Confirm OpenShift is ready].

The current published workshop, playbooks, and prerequisites remain at xref:guides::home.adoc[Development Guides (v1)]. Both sites ship from the same GitHub Pages deploy.

== Overview

Migration Factory is built so you can use OpenShift Virtualization at scale: assess the source estate, run the migration with Migration Toolkit for Virtualization (MTV), and keep managing VMs after they land.

image::guides:ROOT:mf-overview.png[Accelerating migrations at scale with Ansible Automation Platform]

== Ansible collection

The Ansible collection is the content that drives that journey: from existing hypervisors to OpenShift Virtualization, using AAP. It also includes content for managing VM workloads after they run on OpenShift Virtualization.

The project publishes two validated collections on Automation Hub:

* https://console.redhat.com/ansible/automation-hub/collections/validated/infra/openshift_virtualization_migration/details/[OpenShift Virtualization Migration]
* https://console.redhat.com/ansible/automation-hub/collections/validated/infra/openshift_virtualization_ops/details/[OpenShift Virtualization Operations]

This documentation follows the Migration collection on the link:https://github.com/redhat-cop/openshift_virtualization_migration/tree/v2[`v2` branch]. Playbooks, inventory groups, and role names in the left nav match that branch, not `main`.
