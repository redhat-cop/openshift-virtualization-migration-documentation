= Closing the migration wave

The wave is finished when xref:verify-migration.adoc[Verifying a migration] is true: plans **Succeeded**, VMs in `target_namespace`, started if you need them.

Then:

. Hand the VMs to the team that operates OpenShift Virtualization.
. xref:archive-plan.adoc[Archiving the plan] so the Plan CR cannot be started again and MTV can drop logs.
. Leave maps and providers in place if another wave will use them. Remove them only when that pair is retired (xref:scaling-the-automation.adoc[Updating the topology]).

After handover, guest operations are in xref:day2-overview.adoc[Day 2 operations].
