RHDP workshop

Red Hat Demo Platform is a demonstration lab, not the default path. Production and customer work starts at Preparing your environment with your OpenShift and AAP.

Use this catalog item only for enablement: a short-lived OpenShift cluster with Virtualization and MTV, plus a vSphere source. It does not install AAP.

Catalog item: Experience OpenShift Virtualization Roadshow.

Order and collect details

  1. Order the item. Activity: Practice / Enablement. Purpose: Conduct internal training/enablement.

  2. When the service is ready, open Details and copy the OpenShift API and console URLs, admin password, and vCenter host, username, and password.

Then follow the same mainstream path: optional Deploying Ansible Automation Platform (optional), Building your inventory (one cluster, one source), Seeding Ansible Automation Platform.

The older workshop write-up remains at v1 RHDP workshop. Do not use its migration_factory_aap playbook or hub/spoke inventory; collection v2 does not use those.
